# Quellen

Jede Zahl, jede Tatsachenbehauptung und jede Zusage auf der Website braucht
eine Quelle. Ohne Eintrag hier wird die Angabe **nicht** auf die Seite
gebracht.

## Aktuell auf der Seite verwendete Angaben

| Angabe auf der Seite | Wert | Quelle | Bemerkung |
|---|---|---|---|
| Projektphase | „Das Projekt befindet sich im Aufbau" | Betreiber, 08.11.2026 | mündlich bestätigt |
| Name / Domain | SuperIntelNex / superintelnex.com | Betreiber | Domain noch nicht eingerichtet |
| Logo | `assets/logo.svg` | eigene Datei, 08.11.2026 | vom Betreiber erstellt |
| Risikohinweis | Wortlaut Abschnitt `#risiko` | Betreiber, 08.11.2026 | vom Betreiber geliefert, Wortlaut nicht geändert |
| Entwicklungsplan (5 Schritte) | Reihenfolge | Betreiber, 08.11.2026 | bewusst ohne Termine |
| Fehlende Angaben (7 Punkte) | Abschnitt `#offen` | Betreiber, 08.11.2026 | |

## Bewusst nicht auf der Seite

Diese Angaben gibt es nicht. Sie tauchen **nicht** auf, auch nicht als
Platzhalter mit erfundenem Wert:

| Fehlend | Wirkung auf die Seite |
|---|---|
| Token-Kürzel | `#offen` führt es als offenen Punkt |
| Blockchain | dito |
| Gesamtmenge | dito |
| Regeln zur weiteren Ausgabe | dito |
| Verteilung und Sperrfristen | dito |
| Offizielle Token-Adresse | dito |
| Betreiber und Kontaktadresse | `#kontakt` zeigt „Kontaktadresse wird ergänzt" |
| Social-Media-Links | `#community` führt sie als „Wird angekündigt" |
| Hosting-Anbieter | Datenschutzerklärung (Aufgabe 1) bleibt Platzhalter |
| Rechtsform und Sitz | Impressum (Aufgabe 1) bleibt Platzhalter |

## Verbotene Angaben

Diese Muster sind verboten, unabhängig von der Quelle:

- Kurse, Marktkapitalisierung, Handelsvolumen, Token-Preis
- Zahl der Teilnehmer, Halter, Mitglieder, Follower
- Renditeversprechen, Kursprognosen, „Ziel-Kurs"
- Bewertungen, Zertifikate, Audits ohne benannten Prüfer und Bericht
- Partnerlogos, Kooperationen, Händlerlisten ohne unterschriebene Vereinbarung
- „Jetzt kaufen", „Jetzt beitreten"-Kauf-Buttons, Countdown, Warteplätze
- Token-Adresse im Format, das wie echt aussieht, aber nicht existiert

## Nachtrag

Wird eine Angabe ergänzt, gehört hier eine Zeile dazu — mit Quelle, Datum und
der Person, die sie geliefert hat. Ohne Eintrag hier nicht auf die Seite.

```
| Angabe | Wert | Quelle | Datum | Geliefert von |
```
